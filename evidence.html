  1. Download and extract the ZIP package.
  2. Install Python 3.10 or later, then run python run_checks.py from the extracted folder.
  3. Review output/reconciliation_results.csv for all 76 checks, including the Python value, Excel cell and saved value, tolerance, source locator and status.

A clean run reports 76 checks passed and zero failed. It also checks that 61 workbook formulas have saved results and no formula errors. The scripts compare Python outputs with saved Excel values; they do not launch Excel to recalculate the workbook. These checks establish calculation consistency only; they do not validate GFG’s underlying accounting records or constitute audit evidence.
