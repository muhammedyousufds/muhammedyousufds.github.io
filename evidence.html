Accurate status language

Claims used on this site

Avoid sayingUse insteadWhy
“Reproducible analysis”“The case study reports internal checks; public inputs, scripts and workbook are not available for rerun.”A visitor cannot currently reproduce the calculation chain from the public repository.
“AI-verified”“AI-assisted; selected outputs were reviewed by the author.”Human review is not an independent certification of all AI output.
“Approved report” without context“Author-reviewed portfolio copy” where that is the intended status.Readers should not infer approval by EY, GFG, an employer or an external reviewer.
“Audit procedures performed”“45 proposed procedures; none performed.”The work used public disclosures and had no access to company accounting records.
“KAM-validated assessment”“Separate thematic comparison with published FY2025 KAMs.”The KAM comparison followed the independent baseline and is not audit endorsement or quality assessment.

Boundary for this redesign: the complete Python/Excel framework, full risk register, and detailed AI logs remain private. This evidence page reports that limitation candidly; it does not invent public files or validation results.

Suggested public release, if separately authorized

Minimum package for a future reproducibility claim

  1. Public-source reference register with report version, page/note and retrieval date.
  2. Sanitized extracted-input table with units, periods, definitions and source keys.
  3. Calculation scripts and a requirements file, with no secrets or private source data.
  4. Excel workbook with formulas intact and a clear input/output legend.
  5. Reconciliation and quality-check outputs that can be rerun from a clean checkout.
  6. AI validation register separated from human drafting/review corrections.
  7. Independent frozen assessment copy and manifest, separate from KAM comparison materials.
  8. README with exact environment, run command, expected outputs and limitations.

This list is a target structure, not a description of files currently published. The full technical package is intentionally not included in this draft.
